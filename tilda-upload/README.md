# Картинки для загрузки в Tilda

Здесь все картинки новых блоков, которых **ещё нет** на сайте — 39 файлов.

1. Загрузите все файлы из этой папки в Tilda (в любой блок с картинкой или в «Файлы» — главное получить ссылку на каждый файл).
2. Скопируйте ссылки и пришлите мне списком — или вставьте в `links.txt` в корне репозитория (по одной на строку) и запустите `node set-links.mjs && node build.mjs`.
   Файл узнаётся по имени, порядок неважен. Имена файлов не меняйте.
