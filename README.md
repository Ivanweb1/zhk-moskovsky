# ЖК «Московский» — новые страницы для Tilda

Вёрстка новых страниц сайта [жкмосковский-симферополь.рф](https://жкмосковский-симферополь.рф/) по макету из Figma и ТЗ.
Каждая страница — **один вайб-блок Tilda**: HTML + CSS + JS одним куском. Шапка и подвал остаются тильдовские.

## Превью

После включения GitHub Pages (Settings → Pages → Branch: `main`, папка `/ (root)`) превью всех страниц будет по адресу
`https://ivanweb1.github.io/zhk-moskovsky/`. Локально: `python3 -m http.server` в папке репозитория → `http://localhost:8000/`.

GitHub Pages нужен и для картинок: блоки берут фото, логотипы банков и иконки из `assets/` по адресу Pages
(`config.json` → `assetBase`). Если удобнее держать картинки в Tilda — загрузите их туда и поменяйте `assetBase` или ссылки.

## Откуда размеры и картинки

Вёрстка сделана по файлу макета (`.fig`, релиз [figma](https://github.com/Ivanweb1/zhk-moskovsky/releases/tag/figma)):
размеры шрифтов, отступы, скругления и цвета взяты из фреймов 1920 / 1440 / 980 / 375.
Фото выгружены из макета (`assets/img/`), логотипы банков и иконки — векторы из макета (`assets/logo/`, `assets/icon/`).

Шрифты в макете — **Sverdlovsk** (заголовки) и **Manrope** (текст). Блоки берут их из настроек сайта Tilda.
В превью Sverdlovsk нет, вместо него стоит близкий по ширине Fira Sans Extra Condensed, поэтому переносы
заголовков в превью могут немного отличаться от сайта.

## Как вставить страницу в Tilda

1. Создайте страницу, в настройках укажите адрес из таблицы.
2. Добавьте шапку и подвал сайта (как на главной), между ними — вайб-блок.
3. Откройте файл из `dist/tilda/…`, скопируйте **весь** код и вставьте в вайб-блок.
4. Опубликуйте.

Шрифты и цвета блоки берут из настроек сайта Tilda (`--t-headline-font`, `--t-text-font`), отдельно ничего подключать не нужно.
Все стили блоков начинаются с `.zm-`, поэтому с остальными блоками сайта они не конфликтуют.

В меню сайта нужно добавить пункты «Ход строительства», «Условия покупки», «Расчёт ипотеки», «Документы», «Новости».

## Формы (заявки)

Формы свёрстаны в коде: валидация имени и телефона, маска `+7 (000) 000-00-00`, обязательная галочка согласия со ссылкой на `/politica`, сообщение «Спасибо» после отправки.
Получатель заявок пока не настроен — сейчас форма показывает «Спасибо», но заявку никуда не отправляет. Варианты:

- **Через штатную форму Tilda (рекомендуется)** — заявки пойдут туда же, куда сейчас (CRM / почта / Telegram):
  1. На этой же странице добавьте блок с формой Tilda с полями `Name`, `Phone`, `Time`, `Comment`, `Calc` (тип «Текст»), подключите получателей и скройте блок.
  2. Узнайте id этого блока (`rec123456789`) и впишите его в код формы: `data-tilda-form="rec123456789"`
     (или в `config.json` → `tildaFormRec` и пересоберите).
- **Через свой обработчик**: адрес в `data-webhook="https://…"` (POST, FormData).
- Страница «Спасибо» вместо сообщения: `data-redirect="/spasibo"`.

## Что и где редактировать

Правьте исходники в `src/blocks/`, затем пересоберите: `node build.mjs` (Node 18+). Можно править и прямо готовый код в Tilda — данные лежат в начале скриптов.

- **Новости** — список хранится в одном месте: в блоке `/novosti`, в `<script id="zm-news-data">` (новые новости — в начало).
  Каждая новость — отдельная страница Tilda с адресом `/novosti/<slug>` и блоком из шаблона; в шаблоне меняются заголовок, текст, дата, фото.
  «Читайте также» на страницах новостей сам подтягивает список со страницы `/novosti`.
- **Ход строительства** — карточки берутся из текущего «Потока» Tilda (id `924680363231`, обложка + галерея поста);
  если поток недоступен, показывается запасной список `REPORTS` в коде (сейчас в нём 7 реальных отчётов с обложками).
  **Проверить на опубликованной странице**, что фото из потока подгрузились. Если нет — заполнить `photos` в `REPORTS`.
- **Документы** — массив `DOCS` в коде (вид, название, тип файла, размер, дата, ссылка). Сейчас: 3 реальных документа с Яндекс Диска + «Проектная декларация» без ссылки.
- **Калькулятор** — блок `CFG` в коде: границы стоимости и срока, программы, банки (ставка, минимальный взнос, срок, логотип).
  Условия банков взяты из макета («Банки-партнёры» на странице «Условия покупки»): Генбанк — от 6%, ПВ от 20,1%;
  «Банк России» — от 5,5%, ПВ от 20,1%; ВТБ — от 6%, ПВ от 40,1%; срок 1–30 лет. Если взнос меньше минимального
  для банка, строка банка показывается неактивной.
- **Карта** на «О проекте» — iframe Яндекс.Карт по запросу «Симферополь, проспект Победы»; лучше заменить на код из конструктора карт с точкой на ЖК.

## Требует уточнения у клиента

- Адрес «О проекте»: в ТЗ встречаются и `/o-proekte`, и `/opisanie-kompleksa`. Сейчас — `/o-proekte`.
- Куда отправлять заявки (CRM / почта / Telegram) — см. «Формы».
- Банки-партнёры и ставки. В макете написано «Банк России» и стоит логотип Центробанка — скорее всего, имелся в виду АБ «Россия»; проверить название и логотип.
- Максимальный срок рассрочки (в калькуляторе стоит 24 мес.) и есть ли разные ставки по программам (семейная, IT и т.д.).
- Финальные тексты (сейчас рыбный текст там, где он был в макете) и фото из Figma.
